# Contributing

Report exact firmware/build, loader provenance/hash, motherboard/controller/NIC PCI IDs, boot mode, storage family, and which validation gates passed. Separate successful scans from successful HAL reverse queries; separate VM results from physical hardware results.

Use invented disk aliases in public reports. Remove IPs, MACs, serials, WWNs, UUIDs, usernames, hostnames, private paths, tokens, file names and personal browser chrome. Never upload original disk images, configuration backups, firmware binaries, credentials or unredacted screenshots. Reports generated by the inventory tool are private by default.

New hardware support needs a reproducible isolated test and a clear unverified list. Do not propose blanket forced assembly, formatting or signature bypasses as recovery steps. Submit documentation corrections and tests with code changes. Run `python3 -m unittest discover -s tests -v`.

Write guides around reader tasks: prerequisites, actions, expected results, troubleshooting and rollback. Keep test scope concise and label examples that need calibration. Put review coverage in the PR description, not the guide. Include only reusable tools, maintained tests and finished figures; omit one-off authoring/debug output. English pages should use English figures; link separately named localized pages for other UI languages.
